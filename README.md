# 🧮 Basic Calculator (Single Operation)

This is a simple Java console-based program that performs **a single arithmetic operation** between two numbers.

## 📘 Description
The program:
1. Asks the user to enter **two numbers**.
2. Asks for the **desired operation** (`+`, `-`, `*`, `/`).
3. Performs the calculation based on the user’s input.
4. Displays the **result** on the screen.

It also handles invalid operations and division by zero.

---

## 🧠 Features
- Supports **addition**, **subtraction**, **multiplication**, and **division**.  
- Uses a **switch statement** for decision-making.  
- Handles **invalid input** and **division by zero**.  
- Simple, beginner-friendly, and fully interactive.
